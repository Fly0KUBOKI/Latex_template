                    latexmk クイックリファレンス
================================================================================

【インストール確認】
  latexmk -version

【基本的な使用方法】

  1. 単一コンパイル
     latexmk main.tex

  2. 自動監視モード（推奨：ファイル保存時に自動再コンパイル）
     latexmk -pvc main.tex
     終了：Ctrl+C

  3. 強制再コンパイル
     latexmk -f main.tex

  4. クリーンアップ（補助ファイル削除）
     latexmk -c

  5. 完全クリーンアップ（PDF も削除）
     latexmk -C

================================================================================
                        .latexmkrc 主要設定
================================================================================

# コンパイラ設定
$pdf_mode = 4;                   # 4 = LuaTeX で直接 PDF 出力
$lualatex = 'lualatex %O %S';    # LuaTeX コマンド

# ビルド設定
$max_repeat = 5;                 # 最大 5 回再コンパイル
$bibtex_use = 0;                 # bibtex 不使用
$makeindex = 0;                  # makeindex 不使用

# 出力制御
@generated_exts = qw(aux log out idx ilg glo acn acr alg);  # 削除対象

# PDF プレビュー
$pdf_previewer = 'start %O %S';  # デフォルト PDF ビューアー
$preview_continuous_mode = 1;    # 自動監視有効
$new_viewer_always = 0;          # 既存ビューアー再利用

================================================================================
                        トラブル対応
================================================================================

【latexmk が見つからない】
→ TeX Live が正しくインストールされているか確認
   Get-Command latexmk

【Perl エラー】
→ TeX Live インストール時に Perl も同時にインストール必要

【PDF が更新されない（-pvc モード）】
→ Ctrl+C で終了し、再度 latexmk -pvc main.tex を実行

【ファイルが更新されない場合】
→ 強制再コンパイル：latexmk -f main.tex
