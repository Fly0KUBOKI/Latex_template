# レポートテンプレート

このフォルダは授業・実験レポートを書くための LaTeX テンプレート一式です。

## 主なファイル構成

- `main.tex` - メインファイル（エントリポイント）
- `macros.tex` - 共通マクロとカスタムコマンドの定義
- `frontcover.tex` - 表紙テンプレート
- `purpose.tex` - 目的
- `principle.tex` - 原理
- `method.tex` - 実験方法
- `result.tex` - 結果
- `consideration.tex` - 考察
- `conclusion.tex` - 結論
- `assignment.tex` - 課題（必要に応じて）
- `sections.tex` - 追加セクション（実験概要・装置材料等）
- `references.tex` - 参考文献

## 使い方

### 1. 基本的な編集方法

1. **表紙の編集**: `frontcover.tex` でタイトル、学科、氏名等を編集
2. **各セクションの編集**: `purpose.tex`, `method.tex`, `result.tex` 等を編集
3. **不要なセクションの削除**: `main.tex` で不要な `\input{...}` をコメントアウト

### 2. ビルド方法

LuaLaTeX を使用してビルドします:

```powershell
cd "C:\Users\takut\OneDrive\ドキュメント\レポート\レポートテンプレート"
lualatex main.tex
```

参考文献を使用する場合は複数回コンパイルが必要です:

```powershell
lualatex main.tex
lualatex main.tex
```

## レポート作成の注意点

### 重要な記述ルール

1. **実験方法は過去形で記述**
   - 例: 「測定した」「作成した」「確認した」

2. **句読点は、。で記述**
   - テンプレートのプログラムで自動的に，．に置換されます
   - 例: 「電圧を測定した。」→「電圧を測定した．」

### 推奨される構成

- **サブセクションを活用**: 内容を構造化して読みやすくする
- **番号付きリスト**: 手順や項目は `enumerate` 環境で記述
- **図表の参照**: `\ref{fig:ラベル}` や `\ref{table:ラベル}` で参照
- **単位の記述**: `\SI{数値}{単位}` コマンドを使用（例: `\SI{10}{\kilo\ohm}`）

## テンプレートの特徴

### 各ファイルにコメント例を記載

各セクションファイル（`purpose.tex`, `method.tex` 等）には、

これらを参考に、自分の実験内容に合わせて編集してください。

`result.tex` に以下の例が記載されています:

- **表の作成例**: `table` 環境と `tabular` 環境の使用方法

- **複数図の並列配置**: `minipage` 環境を使った横並び配置

### 必須の要素

テンプレートには以下の例が含まれています:

- ✓ 表の作成例（測定データの表示）
- ✓ グラフの挿入例（PNG/JPG画像の挿入）
- ✓ 複数図の並列配置例
- ✓ 数式の記述例
- ✓ 参考文献の引用例

## カスタマイズ

### マクロの追加

`macros.tex` に独自のコマンドを追加できます:

```latex
% 例: 微分記号の定義
\newcommand{\diff}{\mathrm{d}}
```

### 分野別パッケージの追加

`macros.tex` でコメントアウトされているパッケージを有効化:

```latex
% 化学式が必要な場合:
\usepackage[version=4]{mhchem}

% 回路図が必要な場合:
\usepackage{circuitikz}
```

## トラブルシューティング

- **画像が表示されない**: ファイルパスと拡張子を確認
- **参照が??になる**: 2回コンパイルを実行
- **単位が正しく表示されない**: `\SI{}{}` コマンドの構文を確認
